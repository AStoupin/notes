Как ускорить расчет хэш и кол-ва строк. Предлагаю добавить блок по поиску id, ,которые удовлетворяют условию диапазона дат. Т.е. определяем мин/Макс id. Затем делим этот диапазон на 10(можно больше) id и для каждого id определяем дату этой строки. Следующим шагом выбираем те id (id_start, id_finish) ,  которые внахлёст покрывают изначальный диапазон. В завершении, производим отбор данных с дополнительным условием по id (id_start/id_finish)

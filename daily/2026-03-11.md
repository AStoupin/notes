Oracle execution monitor real time

```
begin
   dbms_application_info.set_module('my program','starting');
   
   <code>
   
   dbms_application_info.set_action('at point A');
   
   <code>
   
   dbms_application_info.set_action('at point B');
   
   <code>
   
   dbms_application_info.set_action('at point C');
   
   <code>
   
   dbms_application_info.set_action('finished');
end;
```

then while it's running you can track your progress like this:

```
select action
from   v$session
where  module = 'my program';  --< this must match the set_module name
```
